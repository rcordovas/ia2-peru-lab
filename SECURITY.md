# Security policy del laboratorio

Este repositorio contiene debilidades intencionales y datos sinteticos para entrenamiento. No reporte los hallazgos sembrados como vulnerabilidades de un sistema real.

Reglas:
- pruebe solo una instancia autorizada de IA2 Peru;
- no conecte credenciales, PII, cuentas bancarias ni servicios reales;
- no realice denegacion de servicio, persistencia ni movimiento lateral;
- use Burp Intruder con listas pequenas y baja concurrencia;
- destruya o aisle la infraestructura al finalizar la actividad.
